# 安心看股桌面设计系统

## 设计基线

- 产品形态：A 股研究与交易前决策工作台，不是营销页或荐股终端。
- 视觉方向：研究档案台为全局骨架，决策驾驶舱承接核心审查流程。
- 气质：清醒、可信、克制；浅蓝科技感，少量金色提醒。
- 桌面基准：1440 × 900；最低支持 1100px 宽度，不为手机端做本轮设计。

## 色彩令牌

| 角色 | 值 | 用途 |
|---|---:|---|
| Canvas | `oklch(0.975 0.008 248)` | 页面底色 |
| Surface | `oklch(0.995 0.003 248)` | 连续工作画布 |
| Surface subtle | `oklch(0.958 0.018 244)` | 选择态、轻提示 |
| Ink | `oklch(0.245 0.045 252)` | 主文字、关键数字 |
| Muted ink | `oklch(0.500 0.030 250)` | 辅助说明 |
| Primary | `oklch(0.475 0.145 254)` | 主操作、当前导航 |
| Primary strong | `oklch(0.365 0.115 254)` | 强调文字、深色按钮 |
| Gold | `oklch(0.650 0.125 78)` | 规则冲突、需注意的信息 |
| Gold subtle | `oklch(0.965 0.040 86)` | 提醒背景 |
| Border | `oklch(0.895 0.018 246)` | 分隔线 |
| Up | `oklch(0.565 0.205 27)` | 仅用于价格上涨 |
| Down | `oklch(0.555 0.135 158)` | 仅用于价格下跌 |

禁止用红色表示普通错误或规则冲突；除涨跌外，状态依靠文字、图标和结构共同表达。

## 字体与数字

- 字体：`Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, system-ui, sans-serif。
- 页面标题 20–24px / 700；模块标题 15–17px / 650；正文 14px / 400–500；辅助信息 12px。
- 关键数字 24–32px / 700；所有金额、比例、代码使用 `font-variant-numeric: tabular-nums`。
- 不使用大写英文 eyebrow 作为每个模块的固定装饰。

## 栅格与密度

- 全局：72px 应用栏 + 248px 股票/任务栏 + 剩余工作区。
- 研究页：主档案 `minmax(620px, 1fr)` + 304px 情境栏。
- 决策页：主审查画布 `minmax(720px, 1fr)` + 304px 证据与规则栏。
- 使用 4/8px 节奏；页面内边距 24px；主要区块间距 20–24px；控件高度 36–40px。
- 圆角：控件 8px，工作区 12px；避免卡片套卡片和大面积悬浮阴影。

## 组件规范

- 导航：图标 + 简短中文，当前项使用浅蓝底和左侧蓝色标记。
- 按钮：主按钮深蓝底白字；次按钮白底细边框；文字操作无边框。所有状态包含 hover、active、focus-visible、disabled。
- Badge：只表达来源、核实状态、规则状态；不用作装饰。
- 表格：固定列对齐、数字右对齐、行 hover；移动信息不塞入多个小卡片。
- Alert：以“发生了什么 + 差值 + 下一步”为结构；规则冲突使用金色，不使用红色。
- 图表：折线为主，事件用垂直锚点；必须提供时间范围、最新值、极值和可读标签。

## 动效

- 状态切换 160–220ms；视图进入仅做 6px 位移与淡入。
- hover 不改变布局尺寸；支持 `prefers-reduced-motion`。
- 不使用跑马灯、卡片堆叠、视差或滚动驱动叙事。

## 禁止项

- 巨型标题、口号、AIDA 营销结构。
- 表情符号充当图标、霓虹暗色金融终端、满屏红绿。
- “AI 正在思考”“我们不会替你决定”等对话式自我说明反复出现在工作区。
- 无意义评分仪表盘、强烈买入/卖出、收益承诺。
- 同质卡片铺满页面、宽阴影和大圆角。
