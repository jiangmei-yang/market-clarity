# ADR-0006：策略研究室作为课程证据 MVP

- 状态：Accepted
- 日期：2026-07-31
- 负责人：产品负责人

## 背景

仓库同时把交易前审查与策略研究室描述为首轮 MVP，导致主指标、受控发布入口和外部用户证据无法归到同一任务。最新产品定义要求用大白话生成、比较、验证并保存研究方法。

## 决定

Module 7/8 的首轮课程 MVP 固定为 `/quant/factors` 的策略研究纵向切片；无引导研究入口为 `/pilot/strategy-lab`，证据汇总位于 `/evaluation`。交易前审查继续作为研究结果的下游使用场景，但不进入本轮主指标。

化名化研究事件使用服务端 HMAC 研究 ID，只保存受邀批次、服务器绑定的用户关系、分群、步骤、耗时、数据模式、错误类别、理解分数和构建号，不保存大白话正文、股票代码、金额或直接身份。只有 `MVP_PILOT_ENABLED=true` 才接收新事件；事件最长保留 90 天并支持参与者提前删除。

## 原因

一个 MVP 只能围绕一个关键假设、一个端到端任务和一个主指标形成可证伪证据。策略研究是当前明确的产品定义，也已经具备受控 DSL、统一回测、锁定测试和版本保存的工程基础。

## 影响

旧交易前审查漏斗仍保留为独立产品研究证据，但不再代表本轮课程 MVP。工程自动化只能证明可运行；在 5 位首轮与 15 位扩展外部样本完成前，不得声称市场验证通过。

## 备选方案

继续以交易前审查为课程 MVP。该方案与最新产品定义不一致，且会让策略研究的大量改进无法对应本轮行为指标，因此未采用。
