# ADR-0002：桌面网页为当前正式交付面

- 状态：Accepted
- 日期：2026-07-29
- 负责人：项目团队

## 背景

仓库保留 Streamlit、独立静态工具、新版 `sites_frontend`、小程序和移动端实验材料。若同时推进多端，会导致同一功能重复实现和验收标准不一致。

## 决定

当前正式交付以桌面网页版为主。新版桌面产品工作优先检查 `sites_frontend/`；旧 Streamlit/FastAPI 实现继续作为业务基线、演示、兼容入口和可复用服务来源。小程序、Android、iOS 和完整 PWA 暂停。

任何任务开始前必须说明目标实现线。不得未经确认在两套界面重复开发同一功能。

## 原因

- 目标用户主要在电脑上研究股票；
- 集中资源完善研究到决策的核心闭环；
- 减少并行平台导致的测试、设计和部署负担；
- 保留旧实现中的业务价值，同时允许新版体验演进。

## 影响

- `sites_frontend/` 成为新增桌面网页工作的优先入口；
- 跨界面规则应继续下沉到 `src/` 或后端服务；
- 历史移动端截图不能证明当前产品完成度；
- 未来恢复其他平台需要新 ADR 和明确资源计划。

## 备选方案

- 同时维护所有平台：当前团队规模下不可持续；
- 立即删除旧实现：会丢失业务基线、演示和兼容能力；
- 只保留 Streamlit：不利于新版桌面产品和组件化演进。
